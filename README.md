## 便携版

在本仓库 Releases 的 **v1.0.2** 下下载 Windows x64 EXE，双击启动，无需安装 Node.js。

- 空白进度，不含制作者日志、截图和个人配置；使用后数据保存在 EXE 同级“助手数据”。
- 设置内选择游戏 Logs 与 Screenshots 文件夹，在底部点击“保存全部设置”。关闭设置不保存草稿。
- 自动截图键 Insert，可设置间隔；只在游戏前台满足条件时按键。空白版自动截图和截图清理默认关闭。
- 默认 F8 显示/隐藏浮窗，可自定义。浮窗跟随开关与主窗口同步，支持滚轮缩放、全屏和 25%～100% 不透明度。
- 点击任务头像或“任务要求”查看详情，关闭按钮固定在顶部；Wiki 由默认浏览器打开。

## 定位与任务限制

位置、朝向来自截图文件名，按截图间隔更新。已接取、失败、交付完成由日志同步；局内逐项目标完成没有可靠日志事件，需要手动勾选或标为可提交。

同一底图可按高度和区域选择不同楼层校准，支持已配置的工厂、中心区、立交桥、储备站和实验室区域；不等于每栋建筑每一层都已校准。破冰船仅负一层、一层、二层有校准；灯塔新版 v1.7 是无定位校准的参考图。未知高度不强行显示默认层定位。坐标规则通过校准点与分层测试，未在游戏内逐地图逐点验收。

任务快照当前含 470 个商人任务、10 个主线章节和 18 个手动攻略补充项；42 项历史任务默认隐藏。缺少真实游戏 ID 的补充任务不能自动同步。资料版本和来源见设置与 data/source.json、data/community/provenance.json。

## 源码运行与打包

在本目录使用 Node.js 24：

```powershell
npm ci
npm test
npm start
npm run package:portable
```

开发服务默认监听本机 127.0.0.1:18765；可用 TARKOV_PORT、TARKOV_STATE_PATH、TARKOV_LOGS_PATH、TARKOV_SCREENSHOTS_PATH 覆盖。也可使用启动助手.cmd。npm run refresh 更新公开任务数据，成功后重启服务。
